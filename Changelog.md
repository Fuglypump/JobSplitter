9/28/2026 Update: Improved Compatibility and Settings Menu

Added:
- Added a configurable mod settings menu using XML Extensions. XML Extensions is an optional integration rather than a hard dependency, Job Splitter continues to function with its default behavior when XML Extensions is not installed. XML Extensions: https://steamcommunity.com/sharedfiles/filedetails/?id=2574315206
- Added individual settings for enabling or disabling Job Splitter worktypes.
- Added optional settings for Nursing to care for prisoners and babies.
- Added optional settings for Rearming for hauling mechanoids to charging stations
- Added optional settings for Butchering for slaughtering animals and executing prisoners.
- Added localization support for the mod settings menu.

Changed:
- Brewing, Refining and Loading have been disabled by default in an effort to reduce clutter, if you want to use them you can turn them back on using the mod settings menu.
- Updated and expanded compatibility patches for current versions of supported mods.
- Updated compatibility patches to account for renamed and Continued versions of supported mods.
- Improved Biotech mechanoid and life-stage worktype integration.
- Due to the extensive backend changes within this update I have ended support for older versions of Rimworld, if you are playing on 1.5 or earlier you can download previous versions of Job Splitter on GitHub: https://github.com/Fuglypump/JobSplitter/releases

Notes:
- XML Extensions must be installed to access the Job Splitter settings menu.
- Changes made in the Job Splitter settings menu require a game restart to take effect.
